# Atividade RTS

Jogo de estratégia em tempo real (RTS). Feito para a cadeira de Padrões de Projetos de Software (Design Patterns).

## Padrões

Usa os padrões Bridge, Composite e Prototype. Na estrutura do projeto, só há pastas para o Bridge e Composite, mas o padrão Prototype foi usado em conjunto com o Composite nos mesmos arquivos.
